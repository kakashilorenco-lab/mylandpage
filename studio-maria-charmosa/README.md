# Studio Maria Charmosa: site

Site de uma página para o Studio Maria Charmosa (Av. Atlântica, 2200, Cavaleiros, Macaé/RJ).
É HTML estático e pode ser hospedado em qualquer lugar: GitHub Pages, Netlify, Vercel ou Hostinger.

## Como editar
- **Dados do studio** (WhatsApp, telefone, Instagram, horários): bloco `CONFIG` no fim do `index.html`.
- **Fotos**: substitua os arquivos em `assets/` por fotos originais em alta resolução, mantendo os mesmos nomes.
  - `salao-vista-mar.jpg`: foto do salão (vertical ou quadrada, mínimo 1200px).
  - `entrada-studio.jpg`: fachada ou entrada.
  - `og-image.jpg`: imagem que aparece ao compartilhar o link (1200×630).
